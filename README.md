# WorldTeam Minecraft Plugin

A Paper/Spigot plugin for Minecraft 1.16.5 that automatically assigns players to scoreboard teams based on their world location.

## Features

- Automatically adds players to teams when they join the server
- Updates team membership when players change worlds
- Three teams: Overworld, Nether, and End
- Automatic team creation and cleanup
- Built-in world name detection

## Installation

1. Download the plugin jar file
2. Place it in your server's `plugins` folder
3. Restart the server

## Configuration

No configuration required - works out of the box!

## Commands

No commands needed - plugin works automatically

## Permissions

No permissions required

## Team Prefixes

- Overworld: §a[Overworld]
- Nether: §c[Nether]
- End: §5[End]

## Compatibility

- Minecraft: 1.16.5
- Server: Paper/Spigot
- Java: 8+
